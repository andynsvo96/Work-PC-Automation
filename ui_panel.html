    Hardware guide for a future owner
    
            
    These are planning baselines for this browser-automation app. The live auto-detect recommendation above remains the safe worker count because browser and website load change over time.
    
            
    
              
    
                Minimum reliable setup
                4 physical CPU cores, 8 GB RAM, and 15 GB free storage. Plan on one browser worker.
              
    
              
    
                Recommended everyday setup
                6+ physical CPU cores, 16 GB RAM, and 30 GB free storage. Better headroom for the app, browser profiles, and more than one worker when live memory allows.
              
    
            
    
            
    Each browser worker is budgeted at about 1.25 GB of RAM. Auto-detect also protects RAM for the operating system and the active desktop/browser session.
